# Hermes Codex Usage Policy v0.1


## Objective

Protect Codex quota.


Codex is a limited high-value engineering resource.



# Allowed


- implementation
- debugging
- refactoring
- test failure repair
- complex code migration



# Forbidden


- brainstorming
- documentation writing
- simple explanation
- literature search
- routine analysis



# Execution Rule


Before calling Codex:


hermes-ops must provide:

1. task description

2. affected files

3. implementation approach

4. acceptance criteria



# Codex Output Requirement


Every Codex task must produce:


- code change
- test result
- git diff summary
